# Embedding sequencing

This project directly encodes a text block as an episodic address. It does not compare the text with stored memories, detector prototypes, or reference vectors.

A frozen transformer represents the complete text block in one pass. Every attended final-layer contextual state becomes one row of an ordered raw matrix `H[T,D]`. Each row is independently min-max normalized across its embedding dimensions, then thresholded by the adjustable scalar `tau_threshold`:

```text
N[t,d] = (H[t,d] - min(H[t])) / (max(H[t]) - min(H[t]))
B[t,d] = 1 if N[t,d] >= tau_threshold else 0
```

A constant raw row has no relative strongest dimensions and is deterministically normalized to all zeros. `N` remains in `[0,1]`, and `B` is a `uint8` matrix containing only zero and one.

## Episode addresses

Each `B[t]` is the binary representation of one contextual token position. The ordered sequence:

```text
[B[0], B[1], ..., B[T-1]]
```

is the exact address of the text episode. Address identity includes the row count, embedding dimension count, bit order, and all binary values. No pooling, detector comparison, similarity search, or top-k selection is applied.

`EpisodicMemoryStore` performs exact process-local lookup by this address. If several text blocks produce the same address, they are retained together in a collision bucket rather than silently overwriting one another. Persistent storage is deliberately not introduced until these encoding and retrieval semantics are established.

## Run

Encode, store, and retrieve one or more text blocks:

```bash
.venv/bin/python main.py --tau-threshold 0.8 "dog" "a second text block"
```

The default output contains each binary address sequence and the episode IDs retrieved from that exact address. Raw and normalized vectors are optional diagnostics:

```bash
.venv/bin/python main.py --tau-threshold 0.8 --debug-encoding "dog"
```

Run the tests with:

```bash
.venv/bin/python -m unittest discover -v
```
