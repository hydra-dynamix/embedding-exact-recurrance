# Embedding sequencing

A frozen transformer represents each complete input in one pass. Every attended final-layer contextual state becomes one row of an ordered sequence.

## Detector reference vectors

A detector reference vector is one raw final-layer contextual vector previously captured from a memory episode. It acts as a prototype: a new token's contextual vector is compared with every prototype in the detector bank. Each reference retains its source episode ID and token offset. A detector therefore represents a previously encountered contextual state, not an individual embedding dimension or a learned classifier.

## Coactivation fingerprints

The complete raw vectors and magnitude-sensitive raw dot-product responses are retained as diagnostics. A bounded detector activation maps cosine similarity from `[-1, 1]` into `[0, 1]`, and `tau_threshold` converts each token's activation row into its primary binary coactivation fingerprint:

```text
S[T,M] = H[T,D] @ W[M,D].T
A[T,M] = (cosine(H[T,D], W[M,D]) + 1) / 2
B[T,M] = A[T,M] >= tau_threshold
```

`B[t]` is the binary detector fingerprint for contextual token position `t`. The ordered matrix `[B[0], B[1], ..., B[T-1]]` is the coactivation fingerprint sequence intended for episode-address sequencing. In Python it is available as a `uint8` tensor through:

```python
experience.coactivation_fingerprint_sequence
```

The demo prints this binary sequence by default:

```bash
.venv/bin/python main.py --tau-threshold 0.8
```

Continuous activations, raw scores, margins, firing states, and detector provenance are diagnostics. Print every diagnostic detector row with:

```bash
.venv/bin/python main.py --tau-threshold 0.8 --debug-detectors
```

No pooling or top-k selection is applied; all population matrices retain the complete contextual-position-by-detector shape.

Run the tests with:

```bash
.venv/bin/python -m unittest discover -v
```
